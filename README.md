# A/B-тест геймификации

Анализ A/B-теста механики достижений за регулярное решение задач.
Период: 3 недели, 5 980 пользователей (A = 2992, B = 2988).
Классы 5–11.

## Ключевой вывод

Эффект **неоднороден по классам**:
- 5–7: сильный положительный (+15…+18 п.п. retention_14)
- 8–9: умеренный (+5…+6 п.п.)
- 10–11: нулевой или значимый регресс

**Рекомендация:** раскатить сегментно на 5–9, доработать для 10–11.
